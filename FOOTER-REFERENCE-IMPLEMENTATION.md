# Footer reference implementation

The approved footer reference specifies:
- Deep forest-green background (`#002f12`-range) with a restrained connected-node pattern.
- Gold headings and labels.
- White body copy, opening-hours table text, newsletter description and quick links.
- Green table borders.
- White icons and a teal newsletter submit button.

The shared footer styles were updated on pages containing the four-column footer. The pattern is implemented as CSS gradients so it does not require an extra image asset. This is a visual approximation of the supplied reference; compare in a browser before final acceptance.
