# Modern design system

## Direction
Premium, welcoming and trustworthy home-care experience. The design layer enhances the migrated source while preserving its page content and public URL paths.

## Tokens
- Forest green: `#075b2b`
- Deep forest: `#063d20` / footer `#032d18`
- Teal: `#087f8c`
- Warm gold: `#eab14d`
- Warm neutral: `#fbfaf6`
- Primary text: `#1c2a22`
- Muted text: `#5b6a61`

## Principles
- Responsive type scale and comfortable line-height.
- Rounded but restrained buttons and content cards.
- Visible keyboard focus and reduced-motion support.
- Existing media and legacy component classes retained to avoid breaking migrated page layouts.
- Footer uses deep forest green, gold headings and white body copy.
- Do not replace original imagery until archive/source recovery is exhausted.
